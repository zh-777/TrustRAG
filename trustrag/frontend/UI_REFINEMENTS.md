# TrustRAG frontend refinements

These are UI refinements to the existing **RAG-1 Axiom** build. They do not represent a new model version.

- Removed duplicate response-mode selector from the top bar; the Axiom mode selector remains in the composer.
- Removed the duplicate account menu from the top-right; account controls remain in the lower-left sidebar.
- Removed appearance controls from the API Keys & Model modal; theme switching remains in the top-right toolbar.
- Removed the empty-state “New Chat” title from the top bar; conversation titles appear only after a conversation exists.
- Disabled launch-time prompt prefill so the composer starts empty.
- Replaced the Axiom logo throughout the UI with the supplied three-node mark.
- Replaced the browser favicon with the supplied mark.
- The Axiom logo remains static normally and animates only while a response is being generated.
